# برنامه‌ی اجرایی Petal

## هدف و محدوده

این برنامه نقشه‌ی راه هدفِ تأییدشده‌ی Petal را مشخص می‌کند: مدیریت پروژه و تخته‌ی کانبان، ورود آزمایشی، API با FastAPI، ذخیره‌سازی پایدار برای هر کاربر و دستیار AI از طریق OpenRouter. این سند به‌تنهایی مجوز اجرای هم‌زمان همه‌ی مراحل نیست؛ هر مرحله باید پس از تکمیل معیارهای پذیرش خودش بسته شود.

قابلیت‌های تیمی، نقش‌ها و مجوزهای پیچیده، پرداخت، چندسازمانی و هر قابلیت خارج از این فهرست جزو محدوده نیستند.

## فرض‌ها و تصمیم‌های پیشنهادی

- فرانت‌اند موجود در `frontend/` مبناست؛ پیش از بازنویسی، قابلیت‌ها و آزمون‌های موجود را بررسی و حفظ کنید.
- بک‌اند پیشنهادی FastAPI و پایگاه‌داده‌ی محلی پیشنهادی SQLite است. طرح دقیق داده و قرارداد API پیش از پیاده‌سازی مرحله‌ی پایگاه‌داده باید برای تأیید کاربر ارائه شود.
- ورود با نام کاربری `user` و گذرواژه‌ی `password` فقط برای نمونه و توسعه است، نه احراز هویت مناسب محیط تولید. بررسی ورود باید سمت سرور انجام شود؛ روش نشست و تنظیمات محیطی در مرحله‌ی ورود مستند و آزموده شوند.
- کلید OpenRouter و کلید امضای نشست، در صورت نیاز، فقط از متغیرهای محیطی سمت سرور خوانده شوند؛ هیچ کلیدی در کد، مخزن یا bundle فرانت‌اند قرار نگیرد.
- آزمون‌های خودکار AI باید از پاسخ ساختگی استفاده کنند. فراخوانی زنده‌ی OpenRouter برای `2+2` فقط آزمون دستی اختیاری با کلید و اجازه‌ی کاربر است.
- مستندات طراحی و تصمیم‌ها در `docs/` نگهداری شوند؛ README حداقلی بماند.
